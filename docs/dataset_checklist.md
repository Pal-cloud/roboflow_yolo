# ✅ Checklist de Validación de Datasets — Roboflow Universe

Usa esta tabla para evaluar cada dataset candidato antes de descargarlo.

---

## 📋 Criterios de Validación

| Criterio | Descripción | Peso |
|---|---|---|
| **Nº imágenes** | Mínimo recomendado: 300+ imágenes | Alto |
| **Split train/val/test** | Debe tener las 3 particiones | Alto |
| **Clases correctas** | La clase es el logo de la marca (no el producto) | Alto |
| **Anotaciones visibles** | Bounding boxes bien ajustados al logo | Alto |
| **Licencia** | CC BY 4.0, MIT, o similar que permita uso educativo | Alto |
| **Formato compatible** | YOLOv8 disponible para descarga | Alto |
| **Diversidad de imágenes** | Variedad de fondos, ángulos, tamaños | Medio |
| **Nº descargas / estrellas** | Indica calidad validada por la comunidad | Medio |
| **Augmentations aplicadas** | Flip, crop, color jitter, etc. (data augmentation) | Bajo |
| **Modelo entrenado disponible** | Bonus: ya existe un modelo entrenado | Bajo |

---

## 🏷️ Escala de puntuación por criterio

- ✅ Cumple completamente
- ⚠️ Cumple parcialmente
- ❌ No cumple / No disponible
- ❓ No verificado (requiere abrir el dataset)
